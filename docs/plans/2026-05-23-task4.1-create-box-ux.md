# Task 4.1 Create Box UX Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make Create Box default to a short, reliable first-run path while preserving advanced controls behind a collapsed section.

**Architecture:** Keep the behavior inside the existing dashboard Create Box sheet. Put reusable defaults and labels in `createSandboxForm.ts`, keep the form submission contract unchanged, and use existing UI primitives and styles.

**Tech Stack:** React 19, TanStack Form, Radix/shadcn UI primitives, Vitest, Nx/Vite dashboard build.

**Current Status - 2026-05-23:** Implemented and locally verified. The final UX keeps Resources in the main form and only keeps Lifecycle, Environment Variables, Labels, and Network in Advanced settings.
